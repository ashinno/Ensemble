How it stays in sync

Two Macs with two clocks and two Wi‑Fi radios should sound like one speaker, not an echo. Three mechanisms make that happen.

Capture without a cable

Ensemble taps the audio your Mac is already playing with Core Audio's process tap. Nothing to install, no virtual device, and it can mute the original so the host's own speakers join the ensemble with the same delay as everyone else.

Capture buffer
128 frames · 2.7 ms
Microphone
never

Clocks that agree

Every packet carries the host's capture time. Each receiver measures its clock offset ten times a second, keeps only the fastest round trips, and steers playback by nudging its rate a fraction of a percent so drift never builds up.

Offset accuracy
± 0.03 ms
Rate nudge
≤ 0.4 %

The smallest delay that works

Auto mode measures how late audio really arrives on each Mac and picks the shortest delay the network can carry: raising within two seconds when it must, lowering step by step when it can, and jumping every Mac at once so they never drift apart.

Ethernet
40–60 ms
Wi‑Fi
150–300 ms

Two roles, one window

Pick Host on the Mac that plays, Receiver on the ones that listen. Everything that matters is a module; everything else waits behind Diagnostics.

Everything a house full of Macs needs

Built for one person's living room, not a product roadmap. Each module does one thing.

Finds every Mac by itself

Hosts announce themselves over Bonjour. Receivers list them within seconds. One click to connect, or type an IP when you must.

4821

A code, or a nod

Receivers that know the four‑digit code join instantly. Anyone else waits until you click Allow. Only devices on your local network are accepted.

Volume for each room

Every speaker has its own slider on the host, and its own on the receiver. Mute the kitchen without touching the office.

Prove it with a click

Play a click on every Mac at the same instant, or push one through the stream itself. One click means aligned; a double click tells you which Mac to nudge.

Fine‑tune any speaker

Bluetooth speakers lie about their latency. Slide a receiver a few milliseconds earlier or later until the clicks line up.

SyncDirectOff

Your own speakers, your call

Sync delays the host so it plays with the others. Direct keeps video in lip‑sync and lets the other rooms trail. Off sends the sound away entirely.

Survives a flaky network

Sequence numbers, timestamps, a jitter buffer, silence for lost packets, and automatic reconnection. A bad second sounds like a bad second, not a restart.

rtt 3.1 ms · offset +0.02 · drift 0.00
buffer 118 ms · lost 0 · underruns 0

Numbers when you want them

Round trip, jitter, clock offset, buffer, drift, packets lost, underruns, resyncs, and an event log, one click away and out of sight otherwise.

Up and running in a minute

Same app on every Mac. Nothing to configure beyond two permission prompts.

Host Mac

Open Ensemble, press Start

macOS asks once to let Ensemble record this computer's audio. Allow it. If it ever stays silent, turn it on under Privacy & Security → Screen & System Audio Recording.

Every other Mac

Choose Receiver, click Connect

The host shows up under Hosts nearby within a few seconds. Type the pairing code from the host's window, or let the host click Allow.

Getting the app

Copy the zip, open once

Download Ensemble‑0.4.0.zip from the GitHub release (or build it with scripts/make-dist.sh). Unzip, drag to Applications, right‑click → Open the first time. If Gatekeeper refuses:

xattr -dr com.apple.quarantine /Applications/Ensemble.app
